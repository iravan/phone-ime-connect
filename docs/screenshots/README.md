# README screenshots

Drop the PNGs listed below into this folder with the **exact filenames**. The
"Common problems & fixes" section of the top-level `README.md` references them
and they'll render automatically once present.

| Filename | What to capture |
|----------|-----------------|
| `windows-smartscreen.png` | The Windows SmartScreen "Windows protected your PC" dialog, ideally after clicking **More info** so the **Run anyway** button is visible. |
| `macos-gatekeeper.png` | The macOS Gatekeeper block dialog ("Apple could not verify… is free of malware"). |
| `macos-accessibility.png` | **System Settings → Privacy & Security → Accessibility** with PhoneInputConnect in the list, toggle on. |
| `phone-cert-warning.png` | The phone browser's "Your connection is not private" warning, with the **Advanced / Proceed** option visible. |

Tips:
- Crop tightly to the dialog; keep them readable on mobile (GitHub scales width).
- PNG preferred. Keep each well under ~500 KB so the repo stays small.
